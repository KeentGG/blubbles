About this studio

The bot in the middle is drawn by a small deterministic engine: a 64-point silhouette, a projected pair of eyes, and a set of idle motions layered on top. The same code draws the preview, the stills and every exported frame.

Taking it with you

WebP is the best all rounder: soft edges, transparent background, small file. APNG is lossless but heavier. GIF works almost everywhere odd, but only has one transparent colour, so edges are harder and 512 px gets heavy. MP4 has no alpha, so it renders on Ink or Paper.

Stills use the current frame and the export backdrop you picked. Animated exports always render the idle loop, starting at a phase chosen to land between blinks.
